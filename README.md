# 유배자 정규식

[poe.re](https://poe.re)에서 영감을 받은, Path of Exile **한국어 클라이언트** 전용 검색 정규식 생성기 모음.

게임 내 검색창(보관함·야수 우리 등)에 붙여넣으면 값비싼 항목만 강조해 주는 정규식을 만들어 줍니다.

## 탭

| 페이지 | 대상 | 항목 수 |
|---|---|---|
| `beast.html` | 야수사냥(아인하르) 야수 | 51 |
| `scarab.html` | 갑충석 | 115 |
| `tattoo.html` | 선조 문신 | 53 |
| `runegraft.html` | 칼구르 룬 접목 | 31 |

## 원본과 다른 점

- 이름·정규식이 **한국어 클라이언트 기준**입니다. 각 카테고리 전체 한국어 이름과 충돌하지 않는 최소 고유 부분문자열을 자체 계산했습니다.
- poe.re의 코드를 사용하지 않은 독자 구현입니다(원본 저장소에는 라이선스가 없습니다). 시세 데이터만 poe.re의 공개 엔드포인트(economy.poe.re, poe.ninja 기반)를 사용합니다.

## 동작 방식

- 정적 페이지입니다. 페이지가 열릴 때 economy.poe.re에서 실시간 시세를 가져오고, 실패하면 저장소에 커밋된 스냅숏(`data/prices_*.json`)을 사용합니다.
- GitHub Actions(`update-prices.yml`)가 6시간마다 현재 리그명과 시세 스냅숏을 갱신 커밋합니다.

## 데이터 출처

- 원본 도구: [poe.re](https://poe.re) (veiset)
- 시세: poe.ninja (economy.poe.re 경유)
- 한국어 명칭: 한국 서비스 클라이언트 데이터
- 효과·제작법 번역: [poedb.tw](https://poedb.tw/kr/) 참조
